# Security Policy

## Supported Versions

Only the latest major version receives security updates and vulnerability patches:

| Version | Supported          |
| ------- | ------------------ |
| 5.0.x   | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

We take the security of **Antigravity Shield** very seriously. If you discover a security vulnerability, please do NOT create a public issue on GitHub.

### How to report:
1. **GitHub Private Vulnerability Reporting (Recommended):**
   - Go to the **Security** tab of this repository.
   - Click on **Report a vulnerability** to submit your advisory directly and privately to our core maintainers.
2. **Email Disclosure:**
   - Alternatively, email details directly to: `ershad.zolfi@gmail.com`
   - Please include steps to reproduce, impact assessment, and any proof-of-concept.

We will acknowledge receipt within 48 hours and work with you to triage, patch, and coordinate a safe disclosure timeline.
